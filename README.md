Directory API

RENDER LINK _ https://directory-api-vupn.onrender.com/

This is a small Node.js and Express API I built to practice backend development.

The goal of this project was to learn how APIs are structured, how routes and middleware work, and how to document endpoints using Swagger.

What it includes

REST API built with Express

Organized folders for routes, middleware, and database logic

Swagger documentation to test and explore the API

Tech used

Node.js

Express

JavaScript

Swagger

Project structure
directory-api/
├── db/
├── middleware/
├── routes/
├── swagger/
├── server.js
└── package.json

How to run it

Clone the repo:

git clone https://github.com/brunastockett7/directory-api.git


Install dependencies:

npm install


Start the server:

npm start

API docs

After the server is running, open:

http://localhost:3000/api-docs

Why I built this

I built this project to get hands-on experience with backend APIs and to keep improving my skills as I learn.
